## 1. Primer Acceso y Configuración Inicial

### 1.1 Registro de la Empresa

1. Ingrese a la aplicación y haga clic en **"Registrar mi empresa"**.
2. Complete: nombre de la empresa, NIT, correo, contraseña y tipo de negocio.
3. El sistema activa automáticamente los módulos de su tipo de negocio.
4. Comienza con **14 días de prueba gratuita** — acceso completo, sin tarjeta.

> **Tipos de negocio disponibles:** Tienda / ERP General · Prestamista · Parqueadero · Lavadero · Restaurante

### 1.2 Inicio de Sesión

**Con usuario y contraseña:**
1. Ingrese su nombre de usuario y contraseña.
2. Haga clic en **"Ingresar"**.

**Con huella dactilar o reconocimiento facial:** ★ Diferencial
1. Inicie sesión con contraseña por primera vez.
2. Vaya a **Mi Perfil → Seguridad → Registrar huella / rostro**.
3. A partir de ese momento, un toque en el ícono de huella lo autentica al instante.

> El sistema detecta automáticamente el tema claro u oscuro de su dispositivo. También puede cambiarlo desde el ícono de luna/sol en la barra superior.

### 1.3 Configuración Inicial Recomendada

| Paso | Módulo | Qué hacer |
|------|--------|-----------|
| 1 | Grupos de Productos | Crear categorías con colores (ej: "Bebidas" azul, "Snacks" verde) |
| 2 | Productos | Ingresar catálogo con precios, costos e imágenes |
| 3 | Clientes | Importar o crear base de clientes |
| 4 | Usuarios | Crear usuarios para cajeros, operadores, cobradores |
| 5 | Resoluciones DIAN | Configurar si factura electrónicamente |
| 6 | Caja | Realizar primera apertura de caja |

## 2. Punto de Venta — POS Clásico y Touch

El POS tiene dos modos que puede alternar en cualquier momento con el ícono de teclado/pantalla táctil.

### 2.1 Modo Clásico (Teclado / Lector de Barras)

Ideal para tiendas con caja registradora, lector USB o computador.

**Realizar una venta:**
1. Escriba el nombre o código del producto en el campo de búsqueda, o escanee con el lector USB.
2. El producto se agrega al detalle. Ajuste la cantidad si es necesario.
3. Seleccione el cliente (puede dejar "Mostrador" para ventas al público).
4. Haga clic en **"Pagar"**.
5. Seleccione el método de pago:
   - **Efectivo**: ingrese el monto recibido y el sistema calcula el cambio automáticamente.
   - **Transferencia / Nequi / Daviplata**: registre la referencia.
   - **Tarjeta**: el sistema registra la transacción.
   - **Por Cobrar**: la venta queda pendiente y se suma a la cartera del cliente.
6. **Pago combinado:** puede mezclar múltiples métodos en una misma venta. ★
7. Haga clic en **"Registrar Venta"**.

**Escáner por cámara:** ★ Diferencial
- Haga clic en el ícono de cámara junto al campo de búsqueda.
- Apunte el código de barras al recuadro — el sistema lo detecta automáticamente.
- Puede escanear varios productos seguidos sin cerrar la cámara. Un destello verde confirma la lectura.
- **No necesita ningún hardware adicional** — su celular o tablet es suficiente.

**Devoluciones:**
1. Abra el historial de ventas (pestaña "Historial").
2. Busque la venta y haga clic en el ícono de devolución.
3. Seleccione los productos y cantidades a devolver.
4. El sistema genera la nota crédito y reingresa el stock automáticamente.

### 2.2 Modo Touch (Tablet / Restaurante)

Ideal para restaurantes, fruterías, tiendas con tablet o pantalla táctil.

1. Los productos aparecen como tarjetas organizadas por categoría.
2. Toque una tarjeta para agregar el producto al carrito. Toque múltiples veces para aumentar la cantidad.
3. El carrito se muestra en el panel derecho (o como botón flotante en celular).
4. Desde el carrito: ajuste cantidades, elimine ítems, aplique descuentos.
5. Seleccione cliente y método de pago igual que en el modo clásico.
6. Toque **"Registrar Venta"**.

> Use la barra de búsqueda superior para filtrar productos cuando su catálogo es extenso.

### 2.3 Descuentos y Cupo de Crédito

- Aplique descuento por ítem o sobre el total de la venta.
- El sistema valida automáticamente el cupo de crédito del cliente (incluye IVA) antes de aprobar ventas a crédito.
- Si el cliente supera su cupo, el sistema alerta al cajero.

## 3. Cotizaciones y Preventas

1. Vaya a **Cotizaciones** → **"Nueva Cotización"**.
2. Agregue productos, cliente, condiciones y fecha de vigencia.
3. Guarde — se genera un número de cotización que puede compartir con el cliente.
4. Cuando el cliente apruebe: ubique la cotización y haga clic en **"Facturar"**. ★
5. La cotización se convierte en venta en un clic — el stock se descuenta automáticamente.

## 4. Inventario y Productos

### 4.1 Crear un Producto

1. Vaya a **Productos** → **"Nuevo Producto"**.
2. Complete: nombre, código de barras, precio de venta, costo, IVA y stock inicial.
3. Asigne un grupo/categoría para organizarlo visualmente.
4. Agregue imágenes (hasta 3 fotos en alta calidad).
5. Si el producto es perecedero, active **"Maneja Lotes"** para control de vencimientos.
6. Guarde.

**Auto-completado desde base global de productos:** ★ Diferencial
- Escanee o escriba el código de barras.
- Si el código está en OpenFoodFacts o UPCitemdb, el sistema completa nombre y descripción automáticamente.
- Usted solo asigna el precio de venta y el costo.

**Precios con decimales:** ★ Nuevo 2026
- Ingrese precios con centavos usando coma como separador decimal.
- Ejemplo: `$12.500,50` — el sistema formatea automáticamente al estilo colombiano.

### 4.2 Grupos / Categorías de Productos

- Vaya a **Productos → Grupos**.
- Cree grupos con nombre, código y **color identificador** (se usan en el POS Touch).
- Grupos predefinidos del sistema:

| Código | Nombre | Uso típico |
|--------|--------|------------|
| MP | Materia Prima | Insumos de producción |
| PT | Producto Terminado | Artículos para venta |
| AF | Activo Fijo | Equipos y herramientas |
| INS | Insumos | Materiales de operación |
| PLATO | Platos y Preparaciones | Menú de restaurante |
| ENV | Envases / Empaque | Empaques y presentaciones ★ Nuevo |

- Cree grupos personalizados adicionales con los colores de su marca.

### 4.3 Kardex y Trazabilidad

- En cualquier producto, haga clic en el ícono de historial.
- Verá cada movimiento: quién lo vendió, quién hizo el ajuste, la fecha exacta y el motivo.
- Exporte el kardex a Excel desde el botón de descarga.

### 4.4 Control de Lotes y Vencimientos (FEFO) ★

Cuando `Maneja Lotes = Sí`:
1. Al registrar una compra, el sistema solicita número de lote y fecha de vencimiento.
2. En ventas, el sistema descuenta los lotes **más próximos a vencer primero** (FEFO — First Expiration First Out).
3. Recibirá alertas cuando productos estén próximos a vencer.

### 4.5 Ajuste de Inventario

1. Vaya a **Inventario → Movimientos → Nuevo Movimiento**.
2. Seleccione: Entrada, Salida o Ajuste.
3. Elija el producto, cantidad y motivo (daño, robo, merma, donación).
4. El sistema registra quién hizo el ajuste y cuándo.

### 4.6 Carga Masiva por Excel

1. Descargue la plantilla desde **Inventario → Importar → Descargar Plantilla**.
2. Complete con nombre, código, precio, costo, stock.
3. Suba el archivo — todos los productos se importan automáticamente.

### 4.7 Alertas de Stock Mínimo

- Defina el `stock_mínimo` de cada producto al crearlo o editarlo.
- Cuando el stock caiga por debajo del mínimo, aparece en rojo en el listado y se notifica al administrador.

## 5. Compras

### 5.1 Registrar una Compra

1. Vaya a **Compras** → **"Nueva Compra"**.
2. Seleccione el proveedor.
3. Agregue los productos comprados con cantidad, costo unitario, IVA y lote/vencimiento si aplica.
4. Guarde. El sistema actualiza automáticamente:
   - El stock de cada producto (entrada en el kardex).
   - El costo promedio ponderado.
   - Los lotes disponibles para venta FEFO.

### 5.2 Ítems Libres en Compras ★ Nuevo 2026

Registre gastos o compras esporádicas **sin necesidad de crear un producto en el catálogo**.

- En cualquier línea de la compra, active el modo **"Ítem libre"** con el ícono ✏️.
- Escriba el nombre directamente (ej: "Flete de transporte", "Servicio de electricista").
- El ítem se registra en la compra con su valor y queda en el historial.
- Útil para gastos únicos o servicios que no requieren control de inventario.

### 5.3 Orden de los Ítems

- El orden en que agrega los productos a la compra se conserva exactamente al guardar y al reimprimir.
- Reorganice los ítems arrastrándolos si necesita cambiar el orden antes de guardar. ★

## 6. Clientes y Terceros

### 6.1 Crear un Cliente o Proveedor

1. Vaya a **Clientes/Terceros** → **"Nuevo"**.
2. Complete: nombre, identificación, correo, teléfono, dirección.
3. Para facturación electrónica DIAN: llene tipo de documento, DV y responsabilidades fiscales.
4. Si es proveedor, active **"Es Proveedor"**.
5. Defina el **cupo de crédito** máximo si le vende a crédito.

### 6.2 Historial del Cliente

- Haga clic en el cliente → pestaña **"Historial"**.
- Vea: todas las compras, saldo de cartera, días promedio de pago y monto total comprado.

### 6.3 Cartera / Cuentas por Cobrar

- Vaya a **Reportes → Cuentas por Cobrar** o **Clientes → Deudores**.
- Filtre por antigüedad de la deuda: 0-30, 31-60, 61-90, +90 días.
- Haga clic en el ícono de WhatsApp para enviar un mensaje de cobro directamente al cliente. ★

## 7. Órdenes de Trabajo

Módulo para talleres mecánicos, tecnología, servicios de mantenimiento y cualquier negocio basado en servicios.

### 7.1 Crear una Orden de Trabajo

1. Vaya a **Órdenes de Trabajo** → **"Nueva Orden"**.
2. Complete: cliente, descripción del equipo/vehículo, falla reportada.
3. Tome o adjunte fotos del estado inicial ("antes").
4. Asigne un operador responsable.
5. Guarde — la orden queda en estado **"Borrador"**.

### 7.2 Flujo de Estados

```
Borrador → En Proceso → Pendiente de Aprobación → Finalizado
```

- El **Operador** avanza el estado y sube evidencias fotográficas.
- El **Admin** aprueba cuando llega a "Pendiente de Aprobación".
- Al finalizar, los repuestos utilizados se descuentan del inventario automáticamente.

### 7.3 Panel del Operador ★

- Los operadores solo ven las órdenes asignadas a ellos.
- Suben fotos "antes y después", registran repuestos usados y marcan el avance.
- El administrador ve la productividad por operador en **Reportes → Productividad**.

## 8. Producción y Recetas

Ideal para panaderías, cocinas, laboratorios y fábricas pequeñas.

### 8.1 Crear una Receta (BOM)

1. Vaya a **Recetas** → **"Nueva Receta"**.
2. Seleccione el **producto terminado** a fabricar.
3. Agregue los ingredientes/insumos con la cantidad exacta por unidad producida.
4. El sistema calcula el **costo de fabricación automáticamente**.

### 8.2 Orden de Producción

1. Seleccione una receta → **"Iniciar Producción"**.
2. Indique la cantidad de unidades a fabricar.
3. El sistema valida que haya stock suficiente de todos los insumos.
4. Al confirmar, los insumos se descuentan del inventario.
5. Al finalizar, el producto terminado se agrega al stock.

> **Diferenciación de categorías:** los insumos (MP/INS) y los envases (ENV) se gestionan por separado, permitiendo costos más precisos en cada receta.

## 9. Caja y Corte Diario

### 9.1 Apertura de Caja

1. Vaya a **Caja** → **"Abrir Caja"**.
2. Ingrese el monto inicial en efectivo (base de caja).
3. Confirme la apertura.

### 9.2 Registro de Gastos

- Durante el día, registre gastos operativos desde **Caja → Gastos**: arriendo, servicios, papelería, etc.
- Cada gasto queda con categoría, descripción y quién lo registró.

### 9.3 Corte de Caja

1. Al finalizar el día, haga clic en **"Cerrar Caja"**.
2. El sistema muestra: ventas en efectivo, por transferencia, recaudo de préstamos y gastos del día.
3. Cuente el efectivo físico e ingrese el monto contado.
4. El sistema calcula automáticamente si hay **sobrante o faltante**.
5. El arqueo queda guardado con fecha, hora y responsable.

## 10. Reportes y Análisis

### 10.1 Dashboard Principal

Muestra en tiempo real sin necesidad de generar reportes:
- Ventas del día (total y número de transacciones).
- Cartera total en calle (cuentas por cobrar).
- Productos bajo stock mínimo (alerta roja).
- Recaudo de préstamos del día.

### 10.2 Tipos de Reportes Disponibles

| Reporte | Qué muestra |
|---------|-------------|
| **Resumen de Ventas** | Ventas por período: total, facturas, ticket promedio, métodos de pago |
| **Productos Vendidos** | Top de productos: unidades, ingresos, margen bruto |
| **Rentabilidad** | Margen de ganancia por producto (precio venta - costo) |
| **Clientes Compradores** | Historial por cliente, frecuencia y montos |
| **Cuentas por Cobrar** | Deudores con aging: 0-30, 31-60, 61-90, +90 días |
| **IVA Neto** | IVA generado en ventas vs. IVA descontable en compras |
| **Productividad** | Órdenes de trabajo por operario: cantidad, tiempo, servicios |
| **Inventario / Kardex** | Valor del inventario, rotación, bajo mínimo |
| **Estado de Resultados** | Ingresos − costos − gastos = utilidad neta del período |

**Filtros:** rango de fechas, producto, cliente, categoría, vendedor — en todos los reportes.

**Exportación:** todos los reportes a **Excel o PDF** con un clic.

## 11. Préstamos y Cartera

Módulo diseñado para prestamistas, cooperativas y cualquier negocio que maneje crédito.

### 11.1 Crear un Préstamo

1. Vaya a **Préstamos** → **"Nuevo Préstamo"**.
2. Seleccione el cliente.
3. Use el **simulador integrado**: ingrese monto, tasa de interés, número de cuotas y periodicidad (diario / semanal / quincenal / mensual).
4. El simulador muestra la cuota calculada y el total a pagar antes de confirmar. ★
5. Configure la tasa de mora (porcentaje mensual por cuotas vencidas).
6. Confirme → el sistema genera automáticamente el plan de pagos con fechas exactas.

### 11.2 Ver el Estado de un Préstamo

- Cuotas pagadas, cuotas pendientes, mora acumulada, saldo total.
- Los días de mora se calculan y actualizan automáticamente cada día. ★

### 11.3 Abono a Capital

1. Abra el préstamo → **"Abono a Capital"**.
2. Ingrese el monto a abonar.
3. El sistema descuenta del capital y redistribuye el saldo entre las cuotas restantes — el valor de cuotas pendientes baja automáticamente. ★

### 11.4 Recibo de Pago

- Desde cualquier cuota, haga clic en **"Recibo"**.
- El sistema genera un PDF con: nombre del cliente, monto, fecha, número de cuota, capital + intereses + mora.
- **Envíe el recibo por WhatsApp con un clic.** ★

## 12. Ruta de Cobro en Campo

Módulo para que los cobradores gestionen su cartera desde el celular, sin necesidad de ir a la oficina.

### 12.1 Vista del Cobrador

El cobrador accede al módulo **Ruta de Cobro** y ve:
- Lista de clientes a visitar (cuotas vencidas o con fecha de hoy).
- Ordenadas por zona/sector.
- Estado de cada cuota: pendiente, parcial, vencida.

### 12.2 Registrar un Pago

1. Seleccione la cuota del cliente.
2. Ingrese el monto recibido y el método (Efectivo, Nequi, Transferencia, Tarjeta).
3. Confirme — el sistema actualiza inmediatamente el saldo del préstamo.
4. **Envíe el recibo por WhatsApp desde la misma pantalla.** ★

### 12.3 Evidencia de Visita (GPS) ★ Diferencial

Si el cliente no está o no puede pagar:
1. Haga clic en **"Registrar Novedad"**.
2. Tome una foto del lugar de visita.
3. El sistema guarda automáticamente la **ubicación GPS del cobrador**.
4. Ingrese una nota y programe nueva fecha de visita.

El administrador ve todas las evidencias y la ubicación geográfica de cada visita desde su panel.

1. Vaya a **Parqueadero → Suscripciones** → **"Nueva Suscripción"**.
2. Seleccione el vehículo, fecha de inicio y duración.
3. El sistema muestra alerta roja al escanear una placa con mensualidad vencida. ★
4. Envíe recordatorios de pago por WhatsApp con un clic.

## 15. Catálogo Virtual

Su tienda en línea integrada con WhatsApp — sin costo adicional, sin configuración técnica.

### 15.1 Configurar el Catálogo

1. Vaya a **Catálogo Virtual → Configuración**.
2. Asigne un slug único (ej: `mi-tienda` → la URL será `sistema.com/catalogo/mi-tienda`).
3. Suba su logo.
4. Ingrese el número de WhatsApp donde llegarán los pedidos.

### 15.2 Seleccionar Productos Visibles

1. En el listado de productos, active **"Mostrar en Catálogo"** para cada producto a publicar.
2. Los productos sin stock se ocultan automáticamente del catálogo. ★
3. Los precios se sincronizan en tiempo real desde el inventario.

### 15.3 Cómo Funciona para sus Clientes

1. El cliente entra a su enlace del catálogo.
2. Explora productos por categoría, filtra por precio.
3. Agrega productos al carrito.
4. Hace clic en **"Pedir por WhatsApp"**.
5. Se abre WhatsApp con el pedido ya estructurado — lista de productos, cantidades y total.
6. El cliente envía el mensaje y usted lo atiende.

## 16. Facturación Electrónica DIAN

### 16.1 Configurar la Empresa

1. Vaya a **Configuración de Empresa** como Admin.
2. Active **"Facturación Electrónica"**.
3. Ingrese su API Key de Matias API.
4. Si está en período de prueba DIAN, active **"Modo Prueba"**.

### 16.2 Registrar una Resolución DIAN

1. Vaya a **Resoluciones DIAN** → **"Nueva Resolución"**.
2. Complete: número de resolución, prefijo, rango (desde-hasta), fecha de vigencia.
3. El sistema usa esta resolución automáticamente en cada factura.
4. Recibe alerta cuando el rango esté próximo a agotarse. ★

### 16.3 Cómo Funciona

Al crear una venta con facturación electrónica activa:
1. El sistema asigna automáticamente el consecutivo.
2. Envía el XML a la DIAN vía Matias API.
3. Recibe y almacena el CUFE y el QR.
4. El cliente descarga su factura PDF desde el enlace enviado a su correo.

El estado de cada factura (`Enviado / Aceptado / Rechazado`) es visible en el historial de ventas.

## 17. Administración de Usuarios y Roles

### 17.1 Crear un Usuario

1. Vaya a **Administración → Usuarios** → **"Nuevo Usuario"**.
2. Complete: nombre, usuario, correo, contraseña temporal.
3. Asigne un rol — el usuario accede solo a los módulos habilitados para ese rol.

### 17.2 Roles Personalizados

1. Vaya a **Administración → Roles** → **"Nuevo Rol"**.
2. Asigne nombre y seleccione exactamente qué módulos puede ver y usar.
3. Asigne el rol a los usuarios correspondientes.

**Roles predeterminados:**

| Rol | Acceso |
|-----|--------|
| Admin | Completo — todos los módulos |
| Operador | Solo órdenes de trabajo y panel de productividad |
| Cobrador | Solo la ruta de cobro de sus cuotas asignadas |

### 17.3 Impersonar una Empresa (Solo SuperAdmin)

1. Vaya a **Gestión de Empresas** → busque la empresa.
2. Haga clic en **"Ingresar como esta empresa"**.
3. Ve el sistema exactamente como lo ve el cliente — sin afectar sus datos. ★

## Consejos de Uso Diario

| Situación | Solución rápida |
|-----------|----------------|
| No encuentro un producto en el POS | Use el escáner de cámara o busque por código de barras |
